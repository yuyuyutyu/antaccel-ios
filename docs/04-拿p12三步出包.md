# 04 · 手上有 p12,只想拿包去签:三步走

## 0. 先把话说透

你要的是"一个能丢进签名工具的包"。包里最关键的那 1~30 MB 是 **编译出来的 Mach-O 可执行文件**,
它只能由 Apple 工具链(Xcode / swiftc / clang + iOS SDK)生成,任何打包、改名、解压重组都变不出它来。

所以交付拆成两半:

- **壳的源码 + 工程 + 资源**:已经全给你了(`ios/` 目录,9 个 Swift 文件、完整 `.xcodeproj`、原包资源)
- **把它编成 .ipa**:一条云流水线,3~6 分钟,产出物正好就是你要丢进 ESign 的那份

另外:你本机已经有两份现成的 IPA,其中一份是真·未签名包,可以拿来**先验证你买的 p12 好使**。这一步别跳过。

## 第一步(3 分钟):拿现成包验证你的 p12

你这台机器上有:

| 文件 | 情况 |
|---|---|
| `D:\迅雷下载\navo-4.3.3+433-unsigned-noads.ipa` | `Runner.app` / `im.navo.app` / min iOS 17.0 / **没有 _CodeSignature**,真·未签名 53.9 MB |
| `D:\迅雷下载\TrollInstallerX_汉化版_1.0.2.ipa` | `com.Alfie.TrollInstallerX` / 已带签名段 7.3 MB |

拿 navo 那份跑一遍重签,能装上 = 你的证书、描述文件、包名规则全对;装不上 = 现在就暴露问题,省得做到最后一步返工。

    cd "C:\ipa workplace\out\resign"
    .\inspect_signing.ps1 -P12 你的.p12 -P12Password 口令 -Profile 你的.mobileprovision
    .\resign.ps1 -Ipa "D:\迅雷下载\navo-4.3.3+433-unsigned-noads.ipa" -P12 你的.p12 -P12Password 口令 -Profile 你的.mobileprovision -Zsign zsign.exe

体检器第 6 段会直接打印 ESign 要填的那几栏,照抄。

## 第二步(3~6 分钟):出我们壳的未签名 IPA

不用买 Mac。GitHub 免费额度足够,浏览器点几下:

1. 新建一个空仓库,把 `C:\ipa workplace\out` 里的东西**全部**推上去(这个目录已经是仓库根结构,`.github/workflows/` 就在位);
2. Actions 页面会自动认出 `build-signed-ipa`,点 `Run workflow`;
3. 等绿色勾,进这次运行,底部 `Artifacts` 下载 **`AntiAccel-unsigned-ipa`**;
4. 解压得到 `AntiAccel-unsigned.ipa` —— 这就是你要的"包"。

不想走网页也行,本地装了 git 就四条命令:

    cd "C:\ipa workplace\out"
    git init && git add -A && git commit -m "ios shell"
    git remote add origin https://github.com/你的用户名/仓库名.git
    git push -u origin main

工作流会跑两件事:出未签名包(必出),以及**如果你配了 p12 secrets,顺带把签名包也出了**(纯云签名,连 ESign 都省了)。

配 secrets 就是在仓库 Settings -> Secrets and variables -> Actions 里加:

    P12_BASE64       [Convert]::ToBase64String([IO.File]::ReadAllBytes("cert.p12")) | Set-Clipboard
    P12_PASSWORD     你的口令
    PROFILE_BASE64   [Convert]::ToBase64String([IO.File]::ReadAllBytes("profile.mobileprovision")) | Set-Clipboard

## 第三步(2 分钟):丢进 ESign 签

ESign(全能签 / 轻松签 同理)的流程:

1. 桌面 ESign -> **签名** -> 导入 `AntiAccel-unsigned.ipa`;
2. 设置里先配好 **证书**(`.p12` + 口令)和 **描述文件**(`.mobileprovision`);
3. 点 App -> **签名** -> 选证书 -> **Bundle ID 改成描述文件里那个**(体检器第 6 段给了具体值);
4. 签名完成后在 ESign 里点安装;
5. 首次打开若提示未受信任:设置 -> 通用 -> VPN与设备管理 -> 信任证书名。

爱思助手路径:工具 -> IPA 签名 -> 选 IPA + p12 + 描述文件 -> 填 Bundle ID -> 签名 -> 安装。
Sideloadly:拖入 IPA -> `Apple ID / Certificate` 旁边点 `Certificate` 填 p12 路径与口令 -> Start。

## 参数对照表(唯一会填错的三栏)

| 栏位 | 填什么 | 从哪来 |
|---|---|---|
| 证书 | 你的 `.p12` + 口令 | 你买的那个 |
| 描述文件 | `.mobileprovision` | 必须与证书同一 TeamID |
| Bundle ID | 描述文件 `application-identifier` 去掉 TeamID 前缀 | 体检器第 6 段直接给 |

entitlements 这一栏:本壳零特殊资质(不用 VPN 扩展、不用推送、不用 iCloud),ESign 里保持默认即可。
填错会报 `entitlements mismatch`,不是证书的问题。

---

## 常见坑

| 现象 | 原因 | 处置 |
|---|---|---|
| 装完点开闪退 | 描述文件过期/掉签 | 体检器看 `到期` 一栏,重取 |
| 提示 App 无法安装 | Bundle ID 与描述文件不一致 | 照体检器第 6 段改 |
| 装完是灰图标 | 证书被吊销 | 找卖家换证书 |
| 提示设备未授权 | 开发/Ad Hoc 证书,UDID 不在列表 | 换企业证书,或把 UDID 报给卖家 |
| ESign 签名报错 0x2 | 描述文件里缺对应 entitlement | 用本壳(零资质)不会遇到 |

## 顺带一句:如果你的机器能装 TrollStore

你盘里有 `TrollInstallerX`,说明你摸过这套。iOS 14.0 ~ 16.6.1(部分 17.0.0)装了 TrollStore 之后,
**未签名 IPA 直接装,不用 p12、不用证书、不掉签**。那条路上你只需要第二步产出的 `AntiAccel-unsigned.ipa`,
丢进 TrollStore 就是永久的。
