# 05 · 一条命令出包(不装 git、不用 Mac)

> 前提:你的 p12 已经在全能签里跑通了(已确认)。剩下的只差一个 **未签名 IPA**。
> 这个脚本把"建仓 → 上传 → 触发云端编译 → 下载产物"全串起来,你只敲一行命令。

## 1. 准备一个令牌(一次性,2 分钟)

GitHub -> 右上角头像 -> **Settings** -> 左侧最下 **Developer settings** -> **Personal access tokens** -> **Tokens (classic)** -> **Generate new token (classic)**:

- Note:`ipa-build`
- Expiration:7 天足够
- 勾选 **`repo`** 和 **`workflow`**(两个都要)
- 生成后复制 `ghp_...`(只显示一次)

## 2. 敲这一行

    cd "C:\ipa workplace\out\tools"
    .\push-and-build.ps1 -Token ghp_你的令牌

想指定仓库名/账号:

    .\push-and-build.ps1 -Token ghp_xxx -Owner 你的GitHub用户名 -Repo antaccel-ios

先看清要推什么(不联网、不消耗额度):

    .\push-and-build.ps1 -DryRun

## 3. 它替你干的八件事

1. 校验令牌,拿到你的用户名;
2. 仓库不存在就建(public,免费 macOS 分钟不限额);
3. 把 40 个文件逐个转 base64 上传成 Git blob;
4. 组 tree、写 commit、更新 `main` 分支;
5. 等 GitHub 索引完工作流,POST 触发 `ios-build.yml`;
6. 每 15 秒轮询运行状态,实时打印 `in_progress / success`;
7. 成功后下载 Artifacts,解压出 `.ipa`;
8. 落到 `C:ipa workplaceoutuild-out`,文件名报给你。

全程 3~6 分钟,第一次跑会慢一点(云端要装 xcodegen、下依赖)。

## 4. 拿到包之后

    产物: C:\ipa workplace\out\build-out\AntiAccel-unsigned.ipa

全能签 -> 签名 -> 选这个 IPA -> 证书选你买的那套 p12 + 描述文件 -> **Bundle ID 填** `com.arknet.shell` -> 安装。

Bundle ID 想换成描述文件里的那个也行,脚本注释里写了改法(`ios/AntiAccel/Info.plist` 与 `project.yml` 各一处)。

## 5. 常见报错对照

| 报错 | 原因 | 处置 |
|---|---|---|
| `401 Bad credentials` | 令牌复制不全/已过期 | 重新生成,勾 `repo`+`workflow` |
| `403 Resource not accessible by integration` | 令牌缺 `workflow` 权限 | 重发令牌 |
| `404 Not Found`(建仓后) | 组织仓库需管理员授权 | 改用你个人账号的 `-Owner` |
| `422 Workflow does not have 'workflow_dispatch' trigger` | 工作流文件没进到默认分支 | 脚本会自动重试 6 次;仍失败就把分支设成默认分支 |
| `构建失败` | 看 `html_url` 里的日志 | 多半是 `xcodegen` 或 scheme 名不一致,报给老子 |
| 私有库 Actions 不跑 | 私有库默认要手动开启 | Settings -> Actions -> General -> Allow all actions |

## 6. 死都不给令牌的备用走法

纯网页,不装任何东西:

1. GitHub 新建仓库;
2. 网页点 **Add file -> Create new file**,文件名输入框里直接打 `.github/workflows/ios-build.yml`(斜杠会自动建目录),把 `out/.github/workflows/ios-build.yml` 的内容整个粘进去,提交;
3. 再点 **Add file -> Upload files**,把 `out` 里的 `ios`、`resign`、`nodes`、`docs` 四个文件夹和 `README.md` 一起拖进去(Chrome/Edge 会保留目录层级),提交;
4. Actions -> `build-signed-ipa` -> Run workflow -> 下 `AntiAccel-unsigned-ipa`。

网页拖拽唯一坑:隐藏目录 `.github` 常常被资源管理器跳过,所以第 2 步单独手建。
